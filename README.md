# 🏛️ PTT-Calculator (의성군 맞춤형 취등록세 & 등기비용 상담 계산기)

> **경북 의성군 관할 부동산·농지 취등록세 및 법정 공적 부대비용 전문 상담용 PWA 웹 애플리케이션**  
> 실정법 및 조례 전수 검증 기반: `취등록세 치트시트 사양서.md` (v1.3.0) 및 `PTT_계산기_앱_상세설계서.md` 완벽 구현  
> 레퍼런스: [ansimple/Inheritance-calculator](https://github.com/ansimple/Inheritance-calculator) 경량 PWA 아키텍처 계승

---

## 🌟 핵심 기능 및 특징

1. **One-Input Multi-Output (1회 입력 - 전 감면 시나리오 다중 산출):**
   - 등기할 부동산의 기본 정보(의성군 18개 읍·면, 물건유형, 취득원인, 거래가액, 시가표준액, 면적, 주택수 등)를 1회 입력하면, **일반 과세 및 적용 가능한 모든 감면 시나리오가 백그라운드에서 동시 연산**되어 나열됩니다.
   - 생애최초(최대 300만원 면제), 신생아 출산가구(최대 500만원 면제), 다자녀(2자녀 150만 / 3자녀 300만), 자경농민(50% 감면), 귀농인(50% 감면), 농어촌주택개량(280만), 1가구1주택 상속 특례(0.8%) 등 지원.

2. **의성군 공식 실무 점검표 기반 대화형 자격 심사 (Interactive Eligibility Audit):**
   - 카드마다 **[요건 점검 문답]**을 클릭하여 의성군청 재무과 실무 점검표(07번/08번 서식) 기반 법정 요건을 체크하면 **[적격 확정] / [요건 점검 필요]**가 실시간 판정됩니다.

3. **1원 단위 영수증형 상세 명세 (Receipt Breakdown):**
   - 지방세(취득세 본세, 지방교육세, 농특세 읍·면별 85㎡/100㎡ 비과세 분기)
   - 공적 부대비용(국민주택채권 5천원 단수처리 및 일자별 할인율, 인지세법 정부수입인지, e-Form 등기신청수수료)
   - 일반 과세 대비 절세 금액(Δ 절감액) 실시간 비교.

4. **대고객 상담 리포팅 (A4 인쇄 & 카카오톡 요약 텍스트):**
   - **A4 1장 공식 견적서:** `@media print` 최적화 레이아웃으로 현장에서 바로 인쇄 및 PDF 저장 가능.
   - **카카오톡/문자 원클릭 복사:** 상담 시 핵심 정보를 정리한 요약문 즉시 클립보드 복사.

5. **브라운 & 화이트 톤의 전문적인 반응형 UI:**
   - 모바일 단말기, 태블릿, 데스크톱 PC에 모두 최적화된 고급스러운 브라운/스톤 테마.
   - `vite-plugin-pwa`를 적용하여 네트워크가 불안정한 의성군 관내 면 지역 현장에서도 100% 오프라인 구동 지원.

## 🛠️ 기술 스택

- **Framework:** React 18 + TypeScript + Vite 5
- **Styling:** Tailwind CSS (Brown Palette & Print CSS)
- **State Management:** Zustand (LocalStorage `persist` 연동)
- **PWA:** `vite-plugin-pwa` (Workbox)
- **Icons:** `lucide-react`
- **Testing:** `vitest`

## 🚀 개발 및 빌드

```bash
# 의존성 설치
npm install

# 로컬 개발 서버 실행
npm run dev

# 단위 테스트 실행
npm test

# 프로덕션 빌드 (PWA 서비스 워커 생성)
npm run build

# GitHub Pages 릴리즈 배포
npm run deploy
```
